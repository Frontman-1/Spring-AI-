# Spring-AI-
Spring AI is a Spring-based framework for building AI-powered applications using models like OpenAI, Gemini, Llama, and Ollama. It provides easy integrations for chat, embeddings, image generation, and prompt-based workflows using familiar Spring Boot patterns.
